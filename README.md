# DevPulse

> **Under Development**
> DevPulse is currently in active development. Features, architecture, and UI may change as the project evolves.

DevPulse is a full-stack web application designed to help developers track and explore their GitHub activity and repositories from a centralized dashboard.

The project is being built as a full-stack application using **React, Node.js, Express, PostgreSQL, and the GitHub REST API**.

## Current Development Status

### Implemented

* User registration and authentication
* Secure password hashing with bcrypt
* Session-based authentication
* Protected backend routes
* PostgreSQL database integration
* Save and manage GitHub repositories
* GitHub repository details integration
* Repository commits with pagination
* Repository contributors with pagination
* Backend input validation and error handling

### In Progress / Planned

* GitHub Issues integration
* GitHub Pull Requests integration
* Developer dashboard
* Repository analytics and statistics
* Frontend integration with the backend API
* UI/UX improvements
